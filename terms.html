Основные понятия

Ядро
Центральная часть операционной системы, которая управляет процессором, памятью и устройствами. Ядро Linux было создано Линусом Торвальдсом в 1991 году.
Linux
Свободная Unix-подобная операционная система, основой которой является ядро, написанное Линусом. Сегодня Linux используется на серверах, смартфонах, суперкомпьютерах и встраиваемых устройствах.
Дистрибутив
Готовый набор программ, объединённых вокруг ядра Linux. Примеры: Ubuntu, Fedora, Debian, Arch.
Открытый исходный код
Принцип разработки, при котором код программы доступен для изучения, изменения и распространения. Linux и Git распространяются именно так.
GPL
Свободная лицензия, под которой распространяется ядро Linux. Она гарантирует, что любой производный код тоже останется открытым.

Git и работа с кодом

Основные понятия

Git
Система контроля версий, созданная Линусом в 2005 году. Она позволяет сохранять историю изменений кода и работать над проектом нескольким людям одновременно.
Репозиторий
Хранилище файлов проекта вместе с историей всех их изменений. Бывает локальным (на компьютере) и удалённым (на сервере, например, на GitHub).
Коммит
Зафиксированное изменение в репозитории. Каждый коммит имеет автора, дату и короткое описание того, что было изменено.

Ветвление и слияние

Ветка
Отдельная линия разработки внутри одного репозитория. Позволяет вести параллельную работу, не мешая основной версии проекта.
Слияние
Объединение изменений из одной ветки в другую. Основной инструмент совместной работы в Git.

Терминал и инструменты

Терминал
Программа, которая позволяет управлять системой с помощью текстовых команд. Один из главных инструментов разработчика.
Vim
Текстовый редактор, работающий в терминале. Известен минимализмом и управлением исключительно с клавиатуры. Линус использует его в работе.
Скрипт
Небольшая программа, автоматизирующая рутинную задачу. Скрипты часто пишут на языках Bash, Python или JavaScript.
