Ядро Linux

Главное достижение Линуса Торвальдса — создание ядра Linux. Первая версия появилась в сентябре 1991 года. Сегодня Linux — это основа для тысяч операционных систем: от серверных Ubuntu и Fedora до Android на смартфонах.

Ядро Linux работает на:

  • 99% суперкомпьютеров из топ-500 мира
  • большинстве веб-серверов интернета
  • смартфонах на базе Android
  • умных телевизорах, роутерах, банкоматах

Именно Linux сделал возможным существование современного интернета и облачных сервисов, которыми мы пользуемся каждый день.

Система контроля версий Git

В апреле 2005 года Линус за несколько дней написал Git — распределённую систему контроля версий. Поводом стало то, что сообщество Linux потеряло доступ к проприетарной системе BitKeeper.

Git оказался настолько удобным, что быстро вытеснил конкурентов. Сегодня он используется в Microsoft, Google, Apple и практически в любой IT-компании. Без Git невозможно представить современную разработку.

Ключевые особенности Git:

Распределённость
Каждый разработчик хранит полную копию репозитория.
Скорость
Все операции выполняются локально и почти мгновенно.
Ветвление
Создание отдельной ветки разработки занимает секунды.

Влияние на индустрию

Linux и Git изменили IT больше, чем большинство коммерческих продуктов. Linux лежит в основе облачных платформ AWS, Google Cloud, Azure. Git стал стандартом для хранения кода и командной работы.

По оценкам, суммарная экономическая ценность Linux измеряется миллиардами долларов. При этом сам Линус никогда не продавал свой код — он всегда оставался открытым.

Награды и признание

За свою работу Линус получил множество престижных наград:

  1. Премия Millennium Technology (2012) — за создание Linux, вручена Технологической академией Финляндии.
  2. IEEE Computer Society Computer Pioneer Award (2014) — за вклад в развитие вычислительной техники.
  3. Медаль Ричарда Столлмана (2016) — за вклад в свободное ПО.
  4. Премия Takeda (2018) — за вклад в развитие интернета.

Несмотря на мировую известность, Линус остаётся скромным и продолжает работать над ядром Linux вместе с тысячами добровольцев по всему миру.
